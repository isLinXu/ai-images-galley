📖 如何获取GitHub Token？
  1. 访问 GitHub Settings → Fine-grained tokens
  2. 选择仅限 isLinXu/ai-images-galley 仓库
  3. 在 Repository permissions 中把 Contents 设为 Read and write
  4. 生成并复制 Token（页面关闭后将不再显示）

⚠️ Token 只在当前标签页会话中保存，关闭标签页后需要重新登录
